TEKSTORA — КОМПЛЕКТ САЙТА

Структура:
- index.html — главная страница сайта.
- app/ — редактор и файлы для установки PWA на Android/iPhone/ПК.
- downloads/Tekstora-Windows.zip — комплект Windows.

ПУБЛИКАЦИЯ:
Чтобы сайт получил общедоступную интернет-ссылку:
1. Загрузить всё содержимое этой папки на статический HTTPS-хостинг.
2. Сохранить структуру папок без переименования.
3. Открыть опубликованный HTTPS-адрес.

ПОСЛЕ ПУБЛИКАЦИИ:
- Android: открыть сайт в Chrome → «Установить приложение».
- iPhone/iPad: открыть в Safari → «Поделиться» → «На экран Домой».
- Windows: скачать ZIP на сайте, распаковать, запустить Start-Tekstora.bat.

ВАЖНЫЕ ОГРАНИЧЕНИЯ:
- Это PWA-сайт, не готовые APK/IPA из магазинов приложений.
- Windows-версия — локальный запускатель в отдельном окне браузера, не скомпилированный EXE.
- Документы пока сохраняются отдельно на каждом устройстве. Аккаунтов и облачной синхронизации нет.
- Этот архив сам по себе не является опубликованным публичным сайтом; для публичного URL нужна загрузка на хостинг.
